# Gameplay Overview

Past Halo titles have several systems that make it feel like a sandbox even though its mostly a straightforward FPS title. This game aims to expand on that core Halo-feel of being a mix of FPS and sandbox elements while expanding to incorporate other strategic elements, which include base building, fortifying, and commanding squads of units. While this game will aim to incorporate various real-time strategy elements like base building and commanding units, we will aim to not overwhelm the player by doing things like making unit production not requiring constant input, and making it so all units obey the same command.
